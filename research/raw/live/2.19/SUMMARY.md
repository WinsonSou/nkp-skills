## 2. Extra facts worth putting in the skills

- **How to read an app version without the release notes:** `kubectl get clusterapps` gives the catalog version; `kubectl get appdeployment <app> -n <ns> -o jsonpath='{.spec.appRef.name}'` gives the pinned ClusterApp; `kubectl get helmrelease -A` status text contains `with chart <name>@<version>`; the pod image tag is the upstream version. All three can differ (see Dex).
- **ClusterApp annotations are the licence/scope source of truth:** `apps.kommander.d2iq.io/licensing`, `/scope` (`workspace` or `project`), `/type` (`nkp-core-platform` vs `internal`), `/dependencies`, `/certifications` (`qualified,airgapped`), `/category`. Use `kubectl get clusterapp <name> -o yaml` before recommending an app.
- **ClusterApp is cluster-scoped**, AppDeployment is namespaced. `kubectl get clusterapps` needs no `-A`; `kubectl get appdeployments -A` does. There is no `apps` resource populated on the management cluster (`kubectl get apps -A` → none).
- **New API groups not in the map:** `clusters.nkp.nutanix.com` (holds `nkpclusters`), `hostagent.nutanix.com` (`hosts`, `assignedhosts`, `hostselectorpolicies`), `git.nutanix.com` (`gitclaims`, `gitclaimusers`), `upgrade.nkp.nutanix.com` (`upgradeplans`), `nkp.nutanix.com` (`capistacks`), `infrastructure.cluster.konvoy.d2iq.io` (preprovisioned*), `workspaces.kommander.mesosphere.io` (workspaces, projects, projectroles, and the `virtualgroup*rolebinding` set), `kommander.mesosphere.io` (`licenses`, `virtualgroups`, `virtualgroupclusterrolebindings`), `kommander.d2iq.io` (`helmreleasestatuses`, `kustomizationstatuses`).
- **`kubectl get nkpclusters` columns:** `NAMESPACE NAME NKP-VERSION KUBERNETES-VERSION PHASE AGE` (PHASE `Reconciled`). `kubectl get clusters` shows `CLUSTERCLASS` and `PHASE Provisioned`. `nkp describe cluster -c <name> -n kommander` prints the CAPI tree.
- **kubeadm hardening seen in the apiserver flags:** `--profiling=false`, `--service-account-lookup=true`, `--enable-admission-plugins=DenyServiceExternalIPs,EventRateLimit,NodeRestriction`, `--audit-log-*` (maxage 30, maxbackup 90, maxsize 100) with `--audit-policy-file`, `--encryption-provider-config` (encryption at rest, `providers: [secretbox]`), an explicit FIPS-style `--tls-cipher-suites` list. `serviceSubnet 10.96.0.0/12`, `podSubnet 192.168.0.0/16`, `dnsDomain cluster.local`.
- **Encryption at rest on AHV** is `secretbox` by default (`encryptionAtRest.providers[0].secretbox`).
- **Storage on AHV:** one default StorageClass `nutanix-volume` (`csi.nutanix.com`, WaitForFirstConsumer, Delete, `allowVolumeExpansion: true`, `storageType: NutanixVolumes`, `hypervisorAttached: ENABLED`, `flashMode: DISABLED`, `fstype: ext4`); one CSIDriver `csi.nutanix.com`; one VolumeSnapshotClass `nutanix-snapshot-class` (deletionPolicy Retain). `localvolumeprovisioner` is **not** present on an AHV cluster. Deletion policy is Delete even though the map implies otherwise.
- **COSI is half-wired on AHV:** the `cosi` addon chart 0.2.2 and `objectstorage-controller:v0.2.2` run, `objectstorage.k8s.io` CRDs exist, but there is **no BucketClass and no PV/PVC using it** — the only PVCs use the Nutanix CSI.
- **Namespace labels carry NKP behaviour:** the `kommander` namespace has `pod-security.kubernetes.io/enforce: privileged`, `kubefed.io/managed: "true"`, `workspaces.kommander.mesosphere.io/workspace-name: kommander-workspace`, `kommanderclusters.kommander.d2iq.io/cluster-type: management`, `nkp.nutanix.com/inject-registry-creds: "true"`, `caren.nutanix.com/namespace-sync`.
- **PriorityClasses:** only `dkp-critical-priority` (100002000), `dkp-high-priority` (100001000) plus the two k8s system classes.
- **Only one `LoadBalancer` Service exists** on Starter: `kommander-traefik` in ns `kommander` (ports 8085, 5000, 80, 443), with one ingress IP from the MetalLB pool.
- **kommander-owned controllers you will see in `kommander` ns** (all image `mesosphere/kommander2-core-installer:v2.19.0` unless noted): `kommander-operator` (+ webhook), `kommander-cm`, `nkp-cluster-controller-manager` (+ `nkp-cluster-webhook`), `nkp-management-plane-controller-manager` (+ webhook), `upgrade-plan-controller-manager` (+ `upgradeplan-webhook`), `release-controller-manager`, `loggingstack-controller-manager`, `kommander-capimate` (`mesosphere/capimate:v2.19.0`), `kommander-flux-operator`, `kommander-authorizedlister`, `cluster-observer` (`docker.io/mesosphere/cluster-observer:1.6.0`), `runtime-extension-kommander` (`kommander2-runtime-extension:v1.7.7`).
