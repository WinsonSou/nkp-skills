########## nkp upgrade --help ##########
Upgrade one of [addons, catalog-app, cluster, kommander, platform-apps]

Usage:
  nkp upgrade [command]

Available Commands:
  addons          Upgrade the core Addons in a cluster, one of [aws, azure, gcp, preprovisioned, vsphere]
  catalog-app     Upgrade a Catalog Application to a newer version
  cluster         Cluster one of [eks, metal, nutanix]
  kommander       Upgrade the Kommander version of the targeted cluster
  platform-apps   Upgrade platform applications for a target NKPCluster

Flags:
  -h, --help   Help for upgrade

Global Flags:
  -v, --verbose int   Output verbosity

Use "nkp upgrade [command] --help" for more information about a command.

########## nkp upgrade platform-apps --help ##########
Upgrade platform applications for a target NKPCluster

Usage:
  nkp upgrade platform-apps --cluster-name CLUSTER_NAME --version VERSION --workspace WORKSPACE [--dry-run] [flags]

Flags:
      --allow-gitrepository-catalog-apps   Allow upgrade to proceed when deprecated GitRepository-based catalog apps are detected
      --cluster-name string                Name of target NKPCluster
      --config string                      Config file to use (default "/home/runner/.kommander/config")
      --context string                     The name of the kubeconfig context to use
      --core-app-timeout duration          Timeout to wait for upgrade of each kommander core application (default 20m0s)
      --dry-run                            Do not upgrade, just list the operations that would be performed
  -h, --help                               Help for platform-apps
      --kubeconfig string                  Path to the kubeconfig file to use for CLI requests.
      --platform-apps-timeout duration     Timeout to wait for upgrade of the set of platform applications (default 1h0m0s)
      --request-timeout string             The length of time to wait before giving up on a single server request. Non-zero values should contain a corresponding time unit (e.g. 1s, 2m, 3h). A value of zero means don't timeout requests.
  -v, --verbose int                        Output verbosity
      --version string                     Target NKP platform version to upgrade to
      --workspace string                   Workspace containing the target NKPCluster

########## nkp update controlplane aws --help ##########
Update a Kubernetes cluster control plane in AWS

Usage:
  nkp update controlplane aws [flags]

Flags:
      --ami string                                      AMI ID to use for machines
      --ami-base-os string                              Base OS used in search of AMIs. Examples: 'ubuntu-22.04'
      --ami-format string                               Query string used in search of AMIs. Example: When --ami-base-os='rhel8.10', then the string 'prefix-{{.BaseOS}}-?{{.K8sVersion}}-*' matches any AMIs with the Name 'prefix-rhel8.10-1.36.2
      --ami-owner string                                ID of AWS account used in search of AMIs
  -c, --cluster-name name                               Name used to prefix the cluster and all the created resources.
      --control-plane-renew-certificates-before int32   Enables automated control-plane certificates renewal. Provide the number of days between 7 and 360 when to trigger the certificate renewal.
