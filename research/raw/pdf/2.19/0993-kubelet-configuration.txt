Kubelet Configuration
Customize supported kubelet settings for control plane and worker nodes in NKP 2.18.0 and later.
You can customize kubelet configuration through Cluster API Runtime Extensions (CAREN).
Important:
•
Only documented kubelet settings are supported. Modifications outside this documented
guidance are not supported.
•
Modifying kubelet configuration can trigger a rolling update of affected machines because
these changes are rendered into KubeadmConfig and trigger a node template change.
Kubelet configuration is applied independently to control plane and worker nodes. There is no cluster-level
default. All fields are optional. If you do not set a field, the kubelet default applies.
For more information on the upstream options, see the Kubernetes KubeletConfiguration reference.
Configuration Locations
•
Control plane nodes: clusterConfig.controlPlane.kubeletConfiguration
•
Worker nodes: workerConfig.kubeletConfiguration
