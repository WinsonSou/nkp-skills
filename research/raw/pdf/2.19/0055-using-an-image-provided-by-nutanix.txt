NUTANIX IMAGE BUILDER
Nutanix Image Builder (NIB) enables you to create and manage pre-configured operating systems (OS)
images specifically for running NKP on all supported infrastructure providers. You can first create an image
with all the necessary configurations, drivers, and software needed for NKP. After creating an image, you
can use this image to create NKP clusters. This reduces NKP cluster deployment and upgrade errors
caused by misconfiguration of OS images and packages. Images help you easily manage large NKP
deployments on Nutanix systems.
You can add images in the following ways:
•
Use an image provided by Nutanix, for NKP on Nutanix Infrastructure. For more information, see Using
an Image provided by Nutanix on page 55
•
Build your own customized image for NKP on any of the supported Infrastructure Providers.
Using an Image provided by Nutanix
Nutanix provides pre-built OS images with the tools and configurations required for NKP Kubernetes
cluster deployment. These images are supported exclusively on Nutanix Infrastructure and eliminate the
need to build custom images.
