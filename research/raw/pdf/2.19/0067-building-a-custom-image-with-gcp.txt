10. (Optional) Replicate image to multiple regions:
export GALLERY_IMAGE_LOCATIONS=location1,location2,location3
Replace location1,location2,location3 with a comma-separated list of Azure locations where
you want to replicate the image.
If not provided, the image will only be available in the location specified in the location specified in a
previous step.
11. (Optional) Specify Azure cloud endpoint:
export AZURE_CLOUD_ENDPOINT=Public|USGovernment|China
Replace Public|USGovernment|China with the Azure cloud endpoint you want to use. The default
value is Public
12. (Optional) Specify a custom instance type:
export INSTANCE_TYPE=Instance type
Replace Instance type with the Azure VM instance type to use for building the image. The default is
Standard_D2s_v3.

The NKP CLI command creates an NKP compatible OS image with the configuration and environment
variables in the Azure Shared Image Gallery. This image can be used to create new NKP clusters.
To view all the flags and their purpose, run the following command:
nkp create image azure --help
For the steps to create a cluster, see Azure: Creating a Cluster on page 884.
