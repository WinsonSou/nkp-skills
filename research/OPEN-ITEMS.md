# Open items

This file lists the questions that are still open for the NKP skills. Revisit it before each skill update and each new NKP version.

**How to use this file**
- Each item has an ID, the topic, the open question, the reason it is open, the fastest way to close it, and the skill it blocks.
- When you close an item, move it to "Closed" with the answer, the evidence (the file and source tag), and the date. Do not delete items.
- **Close with:** `lab` = test in the lab (some tests change the lab; get approval first) · `lab-ro` = read-only lab check · `login` = needs a portal login (release notes) · `nutanix` = ask Nutanix · `pro` = needs a Pro or Ultimate license.
